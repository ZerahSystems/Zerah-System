# Zerah System

Software gestionali per imprese e professionisti italiani. Ogni programma è un singolo file: si scarica, si apre con doppio clic e funziona senza installazione e senza internet. I dati restano sul computer dell'azienda.

## Download

Gli eseguibili per Windows (e, a breve, le app Android) si scaricano dalla sezione **[Releases](../../releases)**.

- Windows 10 o 11 a 64 bit
- Android 10 o successivo (app in arrivo)
